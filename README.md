📊 44AI Veri Analiz Portalı (CSV Analyzer)
44AI Veri Analiz Portalı, kullanıcıların CSV dosyalarını yükleyerek saniyeler içinde görsel ve istatistiksel analizler yapmasını sağlayan, Python ve Streamlit tabanlı web tabanlı bir araçtır.

🚀 Uygulamayı Canlıda Dene

https://44ai-csv-tool.streamlit.app/

✨ Özellikler
Kolay Veri Yükleme: Sürükle-bırak yöntemiyle CSV dosyalarınızı anında yükleyin.

Otomatik Veri İşleme: Sütun isimlerini otomatik olarak Türkçeleştirir ve eksik verileri düzenler.

Gelişmiş Görselleştirme:

Sütun Grafikleri (Kategori Dağılımı)

Zaman Serisi (Çizgi Grafikler)

Korelasyon Analizi (Nokta Grafikler)

Kutu Grafikleri (Dağılım Analizi)

İstatistiksel Özet: Veri setinizin temel istatistiklerini (ortalama, standart sapma vb.) anında görün.

🛠️ Kullanılan Teknolojiler
Dil: Python

Arayüz: Streamlit

Veri Analizi: Pandas

Görselleştirme: Matplotlib & Seaborn

💻 Yerel Kurulum (Local Setup)
Projeyi kendi bilgisayarınızda çalıştırmak isterseniz:

1. Bu depoyu klonlayın:
   
   git clone https://github.com/koraycaliskan/csv-analysis-tool.git

3. Gerekli kütüphaneleri yükleyin:
   
   pip install -r requirements.txt

5. Uygulamayı başlatın:
   
   streamlit run app.py
